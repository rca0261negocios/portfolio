# Portfólio Ricardo Andrade

Página de apresentação de trabalhos em TOTVS Fluig e integrações.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `portfolio-fluig`.
2. Envie todos os arquivos desta pasta para a raiz do repositório, incluindo a pasta `media/` e o arquivo `.nojekyll`.
3. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Em alguns minutos o site fica em `https://SEU-USUARIO.github.io/portfolio-fluig/`.

Para trocar o link do formulário, edite o `href` do botão "Preencher a ficha" no `index.html`.
